Manzil Development

Development

Entry points

Manzil exposes flake outputs and a compatible default.nix import.

Useful commands

With flakes Without flakes
nix flake check nix-build -A checks
nix develop nix-shell -A devShell
nix fmt nix run .#formatter --
nix build .#docs-html nix-build -A packages.docs-html
nix run .#manzil-bench -- 2000 20 nix-build -A packages.manzil-bench

Notes

  • The formatter output is formatter.
  • The default shell is devShell in the non-flake entrypoint.
  • Linux checks include NixOS-based tests.
  • The bundled linker package is available as packages.<system>.manzil.
  • The benchmark harness is available as packages.<system>.manzil-bench.
  • The docs site package is available as packages.<system>.docs-html.
